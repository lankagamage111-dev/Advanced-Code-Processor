# Advanced Code Processor

Professional JavaScript obfuscation and HTML/CSS minification tool designed to enhance code security and performance. Powered by **SINHA AI** and **JGS Lanka Co**.

![Project Logo](logo.png)

## Features

*   **JavaScript Obfuscation:** Protect your JavaScript code by making it difficult to understand while maintaining functionality.
*   **HTML Minification:** Reduce the size of your HTML files for faster loading times.
*   **CSS Minification:** Optimize your stylesheets by removing unnecessary whitespace and comments.
*   **File Support:** Easily load files directly or paste code.
*   **Auto-Analyze & Split (Beta):** Advanced feature to analyze and process code chunks.
*   **User-Friendly Interface:** clean, dark-themed UI with progress tracking and statistics.

## Getting Started

To use this tool locally:

1.  **Download the Code:**
    Clone this repository or download the ZIP file.
    ```bash
    git clone https://github.com/yourusername/advanced-code-processor.git
    ```
2.  **Open the Application:**
    Simply open the `index.html` file in your modern web browser (Chrome, Firefox, Edge, etc.).

No installation or server is required for the basic functionality as it runs entirely in the browser using client-side technologies.

## Usage

1.  Select the **Code Type** (JS Obfuscation, HTML Minify, or CSS Minify).
2.  Paste your code into the **Input Code** area or use the "Load File" button.
3.  Click **Process Code**.
4.  View the result in the **Processed Code** area.
5.  Copy or Download the processed code.
